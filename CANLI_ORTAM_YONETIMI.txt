1.1  BULUT SUNUCUSU KIRALAMA
     Durum  : EKSIK
     -------------------------------------------------------
     Uygulamanin 7/24 erisebilir olmasi icin bir sunucu
     gereklidir. Asagidaki seceneklerden biri yeterlidir:

     Ucuz ve Hizli Baslangiç:

       Render.com   → Ucretsiz tier, Docker destekli

     Orta Seviye (Onerilen):

       Hetzner VPS           → Aylik ~4-8 EUR, Avrupa'da hizli

     Kurumsal:
       AWS EC2 / Google Cloud Run / Azure

     Yapilacaklar:

       [ ] Sunucuya Docker kur
       [ ] docker compose up -d ile backend'i ayaga kaldir
       [ ] Sunucu IP adresini kaydet

1.2  DOMAIN (ALAN ADI) ALIMI
     Durum  : EKSIK
     -------------------------------------------------------
     iOS uygulamasi ve API icin gercek bir URL gereklidir.
     Ornek: api.optitrade.app

     Nereden Alinir:
       Namecheap.com, GoDaddy, Cloudflare Registrar
       .app uzantisi: yillik ~15-20 USD

     Yapilacaklar:
       [ ] Domain al (ornek: optitrade.app)
       [ ] DNS ayarlarindan sunucu IP'sini yonlendir
           A kaydı: api.optitrade.app → sunucu_IP

1.3  SSL SERTİFİKASI (HTTPS)
     Durum  : EKSIK — iOS icin ZORUNLU
     -------------------------------------------------------
     Apple, App Store'daki uygulamalarin yalnizca HTTPS
     kullanan API'lere baglanmasina izin verir.
     HTTP baglanti iOS'ta varsayilan olarak engellenir.

     Cozum (Ucretsiz):
       Let's Encrypt + Certbot ile ucretsiz SSL
       Komut: certbot --nginx -d api.optitrade.app

     Yapilacaklar:
       [ ] Sunucuya Nginx kur
       [ ] Certbot ile SSL sertifikasi al
       [ ] Nginx'i FastAPI icin reverse proxy olarak ayarla
       [ ] Sertifika otomatik yenilemesini kur (cron)

1.4  iOS UYGULAMA URL GUNCELLEME
     Durum  : EKSIK
     -------------------------------------------------------
     Su an uygulama localhost:8000'e baglanıyor.
     Yayina almadan once production URL'e guncellenmeli.

     Degistirilecek Dosya:
       OptiTradeiOS/Services/APIService.swift
       Satir: var baseURL: String = "http://localhost:8000"
       Yeni : var baseURL: String = "https://api.optitrade.app"

     Kullanici Ayarlardan da Degistirebilir:
       Uygulama icindeki Ayarlar sekmesi bu degisikligi
       zaten destekliyor. Kullanici kendi URL'ini girebilir.

1.5  ORTAM DEGISKENLERI GUVENLIGI
     Durum  : EKSIK
     -------------------------------------------------------
     Gelecekte eklenecek API anahtarlari (NewsAPI, vb.)
     kaynak kodun icinde olmamali.

     Yapilacaklar:
       [ ] backend/.env dosyasi olustur (zaten .gitignore'da)
       [ ] python-dotenv ile ortam degiskenlerini yukle
       [ ] Sunucuda environment variable olarak tanimla

1.6  RATE LIMITING (ISTEK SINIRLANDIRMA)
     Durum  : EKSIK — Onerilen
     -------------------------------------------------------
     Kotü niyetli kullanicilar ya da hatali istemciler
     sunucuyu cokertebilir.

     Yapilacaklar:
       [ ] slowapi kutuphanesini requirements.txt'e ekle
       [ ] Her IP'ye dakikada maksimum 30 istek siniri koy
       [ ] /scan endpoint'ini daha agir sinirla (10/dk)

1.7  ÖNBELLEKLEME (CACHE)
     Durum  : EKSIK — Performans icin Onemli
     -------------------------------------------------------
     yfinance her cagrida dis sunucuya istek atiyor.
     Ayni sembol icin 5 dakikada bir veri cekip cachelemek
     hem sunucuyu rahatlatir hem kullaniciya hizli cevap verir.

     Yapilacaklar:
       [ ] functools.lru_cache veya basit dict cache ekle
       [ ] Sembol basi 5 dakika gecerlilik suresi koy
       [ ] Tarama (scan) sonuclarini 10 dakika cachele

1.8  HATA IZLEME (ERROR MONITORING)
     Durum  : OPSIYONEL
     -------------------------------------------------------
     Kullanicinin yasadigi hatalari gercek zamanli gormen icin.

       Sentry.io → Ucretsiz plan yeterli
       Kurulum: pip install sentry-sdk[fastapi]
