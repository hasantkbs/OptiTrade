## 2025-10-05 - Performance and Accuracy Improvements

This update focuses on enhancing the performance and accuracy of core OptiTrade components: Price Trend Model, Machine Learning Model, and Backtesting Simulator.

### Improvements

*   **Price Trend Model Accuracy (Weighted Scoring):**
    *   Introduced configurable indicator weights in `src/optitrade/config.py` (`PRICE_TREND_INDICATOR_WEIGHTS`).
    *   Refactored `src/optitrade/models/price_trend_model.py` to use these weights and to return a `pandas.Series` of scores for all data points, enabling vectorized calculations.

*   **Machine Learning Model Accuracy (Enhanced Feature Engineering):**
    *   Added lagged price change and RSI features (1, 2, and 3 days) in `src/optitrade/models/model_utils.py` (`create_features` function) to provide more historical context.
    *   Updated `src/optitrade/models/machine_learning_model.py` to include these new lagged features in its feature set.

*   **Backtesting Performance (Pre-calculation & Vectorization):**
    *   Refactored `src/optitrade/scoring/scoring_engine.py` (`run_engine` method) to accept a DataFrame of pre-calculated individual model scores and return a Series of combined final scores, removing internal data fetching and individual model execution.
    *   Modified `src/optitrade/models/main.py` (`calculate_all_model_scores` function) to return a `pandas.DataFrame` containing scores/regimes from all models (including `MarketConditionClassifier`) for all data points.
    *   Refactored `src/optitrade/models/market_condition_classifier.py` (`generate_score` method) to return a `pandas.Series` of market regimes, enabling vectorized processing.
    *   Updated `src/optitrade/backtesting/simulator.py` to leverage the pre-calculated model scores and the refactored `ScoringEngine.run_engine`, significantly improving backtest performance by replacing iterative score calculation with a single vectorized operation.
    *   Implemented a more vectorized approach for trade simulation within `src/optitrade/backtesting/simulator.py`'s `run_backtest` method, enhancing performance over the original row-by-row loop.
