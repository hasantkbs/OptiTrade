## 2025-09-26 - Comprehensive Enhancements and Bug Fixes

This update includes significant improvements aimed at enhancing the stability, user experience, and accuracy of the analysis models within the OptiTrade platform.

### New Features

*   **Crypto/Stock Analysis Separation:** Separate views for cryptocurrency and stock analysis have been implemented with a toggle switch for easy switching.
*   **New Analysis Intervals:** "1 Week" ('1w') and "1 Month" ('1mo') intervals have been added to the analysis options.
*   **Automated RSI Period:** The manual RSI input has been removed. The RSI period is now automatically assigned based on the selected analysis interval (14 for short-term, 21 for long-term).
*   **Dynamic Tab Title:** When the user switches browser tabs, the tab title dynamically displays the live coin/stock price.
*   **Real-time Price Flash:** A subtle visual flash effect has been added to the 'Instant Price' display in the interface when new prices arrive via WebSocket.

### Bug Fixes and Improvements

*   **Backend 'SyntaxError: expected 'except' or 'finally' block' Resolved:** The missing 'except' block in the `get_trading_signals` function within `src/optitrade/api/server.py` has been added.
*   **`ModuleNotFoundError: No module named 'tweepy'` Fixed:** The `tweepy` library has been added to the `requirements.txt` file.
*   **`NameError: name 'Any'/'Tuple' is not defined` Resolved:** Missing `typing` imports have been added to `src/optitrade/risk/portfolio_optimizer.py` and `src/optitrade/models/base_model.py`.
*   **Model Loading Errors Addressed:** The `ScoringEngine._load_models` method has been refactored for intelligent model instantiation and skipping of abstract classes, resolving `__init__() takes 1 positional argument but 2 were given` and `Can't instantiate abstract class` errors.
*   **Model Standardization:** `BaseModel` and all concrete models have been standardized to use the `generate_score` method and return a dictionary, resolving the `AttributeError: '...' object has no attribute 'predict'` error.
*   **`NameError: name 'DataFetcher' is not defined` Fixed:** Missing `DataFetcher` imports have been added to various model files.
*   **`FinancialRatioModel` Handling for Crypto Assets:** The issue of `FinancialRatioModel` returning a 0 score for crypto assets has been resolved by updating the `ScoringEngine` to skip this model and dynamically set its weight to 0 for cryptocurrencies.
*   **`SupportResistanceModel` Scoring Logic Improved:** The `SupportResistanceModel`'s scoring logic has been enhanced with ATR-based dynamic tolerance, making it more responsive to market volatility and ensuring meaningful scores even when prices are not extremely close to S/R levels.
*   **Chart Visual Enhancements:**
    *   Y-axis labels have been made more compact.
    *   Time information has been removed from X-axis date labels in the price history chart.
    *   Chart margins and font sizes have been adjusted for better readability.
    *   The "Closing Price" in tooltips and legends is now formatted to 2 decimal places.
    *   CSS Grid layout and element heights have been adjusted to prevent chart boxes from overlapping and improve overall UI symmetry and responsiveness.

### Known Issues and Future Developments

*   **Stock View:** The `StockView.js` component is currently a placeholder and does not contain detailed charts/data specific to stock analysis. Future development is planned for this section.
